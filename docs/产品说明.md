# 云屿园区数字孪生运营平台 · 产品说明

> 面向非技术读者，全文约 5 分钟可读完。撰写日期 2026-11-01，对应数据版本 `manifest.json` v1.2.0。

## 这是什么

一个在浏览器里运行的三维园区运营大屏：把虚构的「云屿园区」做成可旋转、缩放、点击的三维场景，完整演示从「发现告警」到「处置归档」的全过程。可以理解为真实园区监控中心大屏的**演示版**——外观、交互、流程与真系统一致，但数据全部模拟生成，不连接任何真实设备。

## 给谁看、什么场景

| 角色 | 用法 |
|---|---|
| 园区值班员（代入） | 总览模式：看概览数字、点楼栋查设备、开关图层 |
| 应急指挥员（代入） | 处置模式：告警定位、调派资源、跟踪处置进度 |
| 参观者 / 汇报对象 | 漫游模式：按 `R` 一键自动巡检，约 3 分钟带讲解看完全部亮点 |

## 核心能力（业务语言）

- **三维看园**：128 栋建筑白模 + 道路 + 湖水 + 周边 115 栋楼宇，片区 → 园区 → 楼栋三级视角平滑下钻；点楼栋看楼层/面积/设备/告警，点设备看温度电流实时曲线，重点楼可「楼层抽离」拆开看内部。
- **告警处置闭环**：告警触发后相机自动飞到事发楼、楼体变红加脉冲，沿「接警→确认→派发→到场→处理→归档」六步推进，可手动也可约 25 秒自动演完。
- **资源调度**：沿园区真实道路网规划最短路径，小车动画行驶到场，时长按路程自适应。
- **复盘与联动**：底部时间轴回放 6 条人车轨迹；点告警趋势图某小时，列表与场景同步筛选高亮；左下 2D 小地图与三维场景双向联动。
- **模拟实时**：每 5 秒推送一条新告警或设备状态；可手动模拟断线，3 秒自动重连且不漏不重。另有模拟视频窗、楼栋/设备搜索（按 `/`）、性能监视面板等辅助功能。

## 典型操作流程

以「14:31 3 号楼烟感报警」为例：列表置顶 → 点击告警，相机 2 秒内飞抵 3 号楼、楼体变红 → 确认警情转「处置中」→ 系统找到最近资源并生成沿路网的路径 → 车辆抵达自动记「到场」→ 现场处理 → 归档后告警转绿、红色标记消失、记录留档。

## 数据规模

全部为模拟数据：建筑 128 栋（重点 12）、设备 90 台（在线率约 97.8%）、告警 28 条（未处置 7）、轨迹 6 条共 1200 点、应急资源 3 处、模拟摄像头 8 个。由固定种子脚本确定性生成，每次重新生成结果一致，总体积约 396 KB，秒级加载。

## 边界与限制

- 演示性质：不接真实 IoT、视频流、调度系统；页面已标注「演示数据」。
- 无后端：没有登录、权限、数据库，刷新后处置记录不保留。
- 仅 PC 本地运行：手机只显示提示页；需 `npm run dev` 启动，无线上地址。
- 底图为网格占位（公开无注记在线底图不可用）；地名全部虚构；性能数据为 1080p 实测，4K 未实测。

## 价值点

- **演示载体**：3 分钟自动漫游即可向非技术观众讲清「数字孪生园区」；
- **方案原型**：处置闭环、路径调度、轨迹回放流程可直接作为真实项目的交互参考；
- **二次开发底座**：数据格式与模块边界清晰，替换数据接口即可演进为真实系统前端骨架。

## 术语白话
