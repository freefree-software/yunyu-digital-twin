## 1. 数据范围

- 园区边界：经度 `120.4145 – 120.426`，纬度 `36.0545 – 36.0645`
- 局部米制换算：以 `(120.4145, 36.0545)` 为原点，`lon = 原点 + x / 90000`，`lat = 原点 + y / 111000`
- 核心运营区约 1.1 km²（虚构园区，页面不出现真实地名）
- 页面展示层不使用任何带注记的底图；Step 1 使用 Cesium 内置网格底图，Step 2 经在线底图验证后仍保留该网格底图（详见 7.1）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | `S-001` – `S-115` |
| height | number | 楼块高度（米），越靠近园区越高（8–42） |

## 4. 业务数据 Schema

### 4.1 devices.json（90）

```json
{
  "id": "D-001",
  "name": "2F 烟感-03",
  "type": "烟感",
  "buildingId": "B-003",
  "buildingName": "3 号楼",
  "floor": 2,
  "status": "warning",
  "temperature": 33.1,
  "current": 0.21,
  "lon": 120.4172018,
  "lat": 36.0617032
}
```

- `status`：`normal` / `warning` / `offline`
- 状态分布：正常 83、预警 5、离线 2（在线率约 97.8%）
- 设备类型：烟感、空调、配电、水泵、门禁、摄像头、电表
- 重点楼宇保底 1 台，其余按建筑面积加权分配（避免全园区设备点过密）
- 锚点：`D-001` 固定为 `B-003`（3 号楼）2F 烟感，供告警演示使用

### 4.2 alerts.json（28）

```json
{
  "id": "A-001",
  "time": "14:31:22",
  "type": "烟感报警",
  "level": "high",
  "status": "pending",
  "buildingId": "B-003",
  "buildingName": "3 号楼",
  "deviceId": "D-001",
  "deviceName": "2F 烟感-03",
  "lon": 120.4172018,
  "lat": 36.0617032
}
```

- `level`：`high` / `medium` / `low`
- `status`：`pending` / `processing` / `resolved`
- 状态分布：待处置 4、处置中 3、已完成 21；未处置合计 7 条
- `A-001` 固定为 3 号楼 14:31:22 烟感报警（待处置），与演示脚本一致
- 时间从 14:31 向前递减，截至当天 08:00 左右；前端按小时聚合为告警趋势

### 4.3 tracks.json（6 条 / 1200 点）

```json
{
  "tracks": [
    { "id": "T-001", "name": "巡逻车-01", "kind": "vehicle", "speed": 7.5, "startTime": "08:12:00", "pointCount": 300 }
  ],
  "points": [
    { "trackId": "T-001", "seq": 0, "lon": 120.4203, "lat": 36.0551, "time": "08:12:00", "speed": 7.6, "heading": 90 }
  ]
}
```

- `kind`：`vehicle` / `person`，各 5 条
- 每条轨迹固定 300 个点，相邻点沿园区道路等距采样
- `time` 为轨迹点对应时刻，`heading` 为行进方向角（度，正北为 0）
- Step 3 轨迹回放直接按 `trackId` + `seq` 读取，不需要额外转换

## 5. 前端接入

| 模块 | 行为 |
|---|---|
| `src/data/campus.ts` | 并行加载园区 GeoJSON 与业务数据，模块级缓存，避免重复请求 |
| `src/stores/dashboard.ts` | 启动时加载；建筑/设备/告警/资源写入 Pinia；概览、设备分布、告警趋势均由数据实时计算 |
| `src/main.ts` | 挂载应用前先 `await store.load()`，避免面板首屏空数据 |
| `src/components/scene/CesiumViewer.vue` | 边界、水系、道路、周边楼宇、建筑拉伸、POI、资源点、设备、告警分图层渲染；图层开关联动 `dataSources.show`；建筑拾取与三级视角相机控制 |
| `src/components/scene/SceneMinimap.vue` | Leaflet 2D 小地图：园区边界 / 道路 / 水系 / 周边楼宇 + 相机视野矩形，双向联动 |

- 影像底图开关切换 Cesium 底图图层显隐
- 设备图层默认开启，展示 90 个状态点（Step 1 为默认关闭，Step 3 起默认开启以便拾取设备）

- 所有坐标直接使用 WGS84 经纬度，无投影偏移；建筑拉伸高度来自 `height` 字段

## 6. 3DTiles 与精细模型说明（降级执行）

按《设计方案》16.4，Step 1 的 3DTiles 切片受阻时立即降级，不阻塞 Step 2。本次执行情况：

- **未生成 30–50 MB 3DTiles**：本机没有 Cesium ion / 离线切片管线；且 30–50 MB 与「首屏 ≤3s」「内存 ≤800MB」目标相冲突
- **当前替代方案**：GeoJSON Polygon + Cesium `extrudedHeight` 拉伸，共 128 栋；重点楼宇加屋顶描边与名称标签
- **12 栋重点楼 glTF 暂缓**：待 Step 2 场景底座定型后，按需接入 `public/models/` 并替换对应拉伸体
- 后续若补齐 3DTiles，只需在 `public/tiles/` 放入 tileset 并新增加载代码，本文件约定的业务 ID 与属性字段保持不变

当前自建数据体积 396 KB，远低于内存与加载约束。

## 7. Step 2 场景底座说明

### 7.1 底图与地形

- 在线无注记影像均不可用（CARTO 返回 KEY REQUIRED 水印、Esri 403、Stadia 401、OSM 带注记不可用），按 16.4 降级
- 当前底图为 `Cesium.GridImageryProvider`（4 格网格、青色低透明度），不加载任何带地名注记的瓦片
- 无 Cesium ion token，无法使用 World Terrain；地形保持椭球平面，三维关系由建筑拉伸高度与相机俯仰表达

### 7.2 三级视角

| 层级 | 触发方式 | 相机参数 |
|---|---|---|
| 片区全景 | 点击场景头部「片区全景」 | `flyToBoundingSphere`，球半径 1900 m，距离 4300 m，俯仰 -55° |
| 园区总览 | 启动默认 / 点击「园区总览」 | 球半径 780 m，距离 1700 m，俯仰 -38° |
| 楼栋近景 | 点击 / 双击建筑，或点击「楼栋近景」 | 以楼栋包围球为中心，距离 300 m 起，俯仰 -42° |

- 飞行时长 1.6–1.8 s，`QUADRATIC_IN_OUT` 缓动；再次触发时新飞行会取消进行中的飞行，相机连续过渡
- 进入楼栋近景后，被选楼栋叠加青色半透明体与屋顶描边；返回园区 / 片区时自动清除选中状态
- 「楼栋近景」在未选中建筑时禁用

### 7.3 图层与 2D 小地图

- 图层：影像底图、建筑白模、周边楼宇、设备点位、告警点位、园区 POI，全部由 Pinia `layers` 驱动 `dataSources.show`，状态保持
- 小地图尺寸 260×170，位于场景面板左下；静态不可拖动，点击地图即飞至对应位置（沿用当前相机高度、朝向与俯仰）
- 相机 `moveEnd` 时用 `camera.computeViewRectangle` 计算视野经纬度范围，同步为主场景上的青色虚线矩形，实现双向联动

## 9. Step 3 业务闭环说明

### 9.1 拾取与信息卡（F4）

- 建筑、设备、告警共用同一套原生 `click` 拾取：优先设备 / 告警点，其次建筑体；拖拽距离 > 4px 不触发
- 点击设备 → 相机下钻到所在楼栋，右上角「设备详情」卡展示类型、楼层、状态、温度、电流与 20 秒滚动实时曲线（ECharts 双轴，2 秒追加一个点）
- 点击建筑 → 「建筑详情」卡展示楼层、建筑面积、设备数、未处置告警数，以及设备状态比例条
- 信息卡右上角关闭按钮回到园区总览

### 9.2 告警定位与处置闭环（F5）

- 点击右侧告警项：`viewLevel` 切到楼栋近景，相机 1.6–1.8 s 飞向告警楼栋；楼体叠加红色半透明体、屋顶红色描边与告警点扩散脉冲
- 场景底部出现处置时间线：接警 → 确认 → 派发 → 到场 → 处理 → 归档
- 逐步推进即更新告警状态：确认后转「处置中」，归档后转「已完成」，告警点从场景移除
- 「自动演示」每 5 秒推进一个阶段，约 25 秒完整演完，无需控制台操作

### 9.3 资源调度与路径动画（F6）

- 右侧「处置资源」列出消防站 / 医疗点 / 应急队，选中告警后才可点击
- 路径基于 `roads.geojson` 构建的节点图（顶点吸附 11 m 网格）用 Dijkstra 计算，起终点吸附到最近道路节点
- 场景绘制青色路径底线 + 高亮行进段 + 红色车辆点与资源名标签；动画时长按路径长度 3.5–9 s 自适应，抵达后自动进入「到场」

### 9.4 轨迹回放（F7）

- 底部时间轴：播放 / 暂停、拖动进度、当前时间、轨迹选择（全部 / 单条）
- 6 条轨迹共 1200 点，一次性预计算为 `Cartesian3` 数组，绘制为静态折线（车辆青色、人员绿色），移动标记由 `CallbackPositionProperty` 每帧读取游标，避免逐帧重建几何
- 时间窗口取所有轨迹首末时间（约 08:12–11:5x），按绝对时间戳二分查找当前点位，各轨迹按各自起始时间错峰出现

### 9.5 2D / 3D 联动与图表联动（F8 / F9）

- 主场景选中对象（告警 / 建筑 / 设备）时，小地图叠加对应颜色定位点与描边圆环，同时保留相机视野矩形
- 点击「告警趋势」折线图任一小时档：列表筛选该小时告警，场景为该批告警叠加蓝色高亮圈；再次点击同一档取消
- 图表整块绘图区可点选（内部按横向像素映射到最近小时档），避免仅能点中数据点

### 9.6 模拟实时链路（F11）

- `src/services/mockRealtime.ts` 本地模拟 WebSocket：每 5 s 交替推送 1 条新告警 / 1 条设备状态，无真实后端
- 新告警插入列表顶部并带 `NEW` 标签，同时进入场景告警图层
- 点击右上角「实时链路」标签模拟断线：立即变「重连中」，3 秒后自动重连并重发断线前最后一条告警；业务层按告警 ID 去重，重复消息计入 `duplicateDropped`

## 10. Step 4 技术深度与性能

### 10.1 自定义 Shader 特效（F13）

- 注册两个 GLSL 材质（`Cesium.Material._materialCache`）：
  - `YunyuBoundaryFlow`：园区边界流光，按 `materialInput.st.s` 与 `czm_frameNumber` 计算光带头部，在环线上循环流动
  - `YunyuScanRing`：园区地面扫描环，以 `st` 到中心距离与 `czm_frameNumber` 相位做径向扩散
- 边界流光与扫描环使用 `Primitive + PolylineMaterialAppearance / MaterialAppearance` 渲染，无需每帧更新 uniform
- 告警扩散沿用告警图层的 `CallbackProperty` 扩散圆，另叠加告警热力光斑（按未处置告警楼宇分层透明圆）
- 三项特效均可在性能面板独立开关，默认开启边界流光、扫描环，关闭热力

### 10.2 楼层抽离（F15）

- 建筑详情卡提供「楼层抽离」按钮：选中楼栋按层拆分为独立体块（最多 12 层）
- `height` / `extrudedHeight` 由 `CallbackProperty` 读取共享 gap，rAF 在 700 ms 内把层间距从 0 拉到 4.5 m
- 抽离期间隐藏原始建筑实体与青色选中体，层块交替配色并叠加 `nF` 楼层标签；收起后恢复原建筑

### 10.3 性能面板（F14）

- 底部「性能监视」打开右下角面板：FPS（500 ms 窗口）、Draw Call、图元数、JS 堆内存、渲染缩放
- FPS 由 `scene.postRender` 计数，Draw Call / 图元数取 `frameState.commandList` 统计
- 画质档位：
  - 高清：`resolutionScale=1`、MSAA×4、FXAA 开
  - 均衡：0.9、MSAA×2、FXAA 关
  - 省电：0.75、MSAA×1，并关闭周边楼宇图层
- 「记录基线」后切换档位可显示 FPS 差值，便于对比优化效果

| 指标 | 数值 |
| --- | --- |
| FPS | 60（稳定） |
| Draw Call | 93–99 |

### 11.1 搜索定位（F17）

- 顶栏搜索框支持楼栋名 / 楼栋 ID / 设备名 / 所在楼栋 / 设备类型的模糊匹配，最多展示 8 条
- 键盘 `↑` `↓` 切换、`Enter` 定位、`Esc` 关闭；全局按 `/` 聚焦搜索框
- 选中楼栋调用 `selectBuilding`，选中设备调用 `selectDevice`，复用三级视角与信息卡逻辑

### 11.2 视频点位（F16）

- 视频点位由 8 栋重点楼宇派生（`CAM-001` 起），红 / 橙点位 + `CAM` 标签，归属于 POI 图层
- 点击弹出模拟视频窗：扫描线、网格、目标框、实时时间戳与码率信息；离线点位显示「信号中断」
- 视频为纯前端模拟，不接入真实流；`Esc` 或右上角关闭

### 11.3 一键自动漫游（F12）

- 顶部「漫游」或快捷键 `R` 启动 / 停止，浮层展示步骤、讲解、进度与上 / 下一段、步骤点跳转
- 7 段共约 180 秒：片区总览 → 园区全貌 → 楼栋下钻 → 告警定位与派发 → 资源路径 → 轨迹回放 → 返回总览
- 漫游直接调用现有 store 动作（`setViewLevel` / `selectBuilding` / `focusAlert` / `planRoute` / `advanceDisposal` / `toggleTrackPlaying`），不新增渲染分支

### 11.4 2K / 4K 大屏（F10）

- 1920×1080 设计稿整体 CSS 缩放不变形
- `CesiumViewer` 读取同一缩放比，将 `resolutionScale` 提升至 `min(2, 档位基准 × 缩放比)`，4K 下用 2 倍绘制缓冲避免放大发糊
- 画质档位与分辨率缩放叠加：高清 1.0×、均衡 0.9×、省电 0.75×（上限 2×）
